# Formula 1 személyes weboldal

Ez a projekt Kecskés Roland Formula 1 témájú személyes weboldala. Az oldal bemutatja a kedvenc pilótámat, Max Verstappent, valamint a kedvenc csapatomat, a Red Bull Racinget.

## Oldalak

- `html/index.html` - Főoldal és bemutatkozás
- `html/pilota.html` - Max Verstappen bemutatása és képgaléria
- `html/csapat.html` - A Red Bull Racing bemutatása

## Stílusok

A weboldal stílusait a `css` mappában található közös és oldalankénti CSS-fájlok tartalmazzák.

## Megnyitás

Nyisd meg az `html/index.html` fájlt egy böngészőben.
